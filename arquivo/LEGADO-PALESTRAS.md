1. O catálogo atual não é sobrescrito por um README legado quando existe uma fonte posterior fornecida pelo autor.

3. Títulos antigos funcionam como aliases e evidência de proveniência.
4. Categorias antigas (`Cyber`, `Psicologia`, `Biohacking`) são preservadas como taxonomia histórica, não como estrutura obrigatória do acervo atual.
5. Arquivos com o mesmo conteúdo foram reaproveitados, evitando duplicação desnecessária.
