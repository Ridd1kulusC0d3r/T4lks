# Slides

[Início](../README.md) · [Catálogo de palestras](../palestras/README.md)

Envie PPTX e, quando possível, PDF para facilitar a leitura no navegador.

Organização sugerida: `slides/ANO/AAAA-MM-DD-evento-tema.pptx` e o PDF correspondente. Se a data não estiver confirmada, use apenas o ano e o slug.

Após o upload, adicione o link à ficha da palestra e ao catálogo. Para arquivos grandes, use um link externo estável ou uma release do GitHub.

**Materiais disponíveis:** nenhum arquivo importado nesta reorganização.
