# Publicar uma palestra

1. Confira título, evento e data na fonte original.
2. Copie [o modelo](templates/palestra.md) para `palestras/ANO/slug.md`.
3. Preencha somente informações confirmadas. Use “A confirmar” para lacunas.
4. Envie os arquivos em **Add file → Upload files** na pasta correspondente ou use links externos.
5. Troque “A adicionar” pelos links reais.
6. Inclua a palestra no [catálogo](palestras/README.md).
7. Abra os links e confira permissões e créditos.

## Importação do Notion

Conferir a página e suas subpáginas antes de criar registros. Preservar o link de origem em cada ficha. Arquivos disponíveis só no Notion devem ser baixados e publicados quando houver autorização, ou referenciados por links estáveis e acessíveis.

Não confundir uma proposta de palestra com uma apresentação já realizada. Não usar a data da edição da página como data do evento.

## Nomeação

Use nomes curtos sem espaços e sem acentos nos caminhos, preservando a grafia correta nos títulos. Exemplo de formato: `AAAA-MM-DD-evento-tema`. Este formato é ilustrativo e não é um evento real.
